
# Minecraft Codespaces Desktop

Ubuntu XFCE desktop dengan noVNC dan Java 21.

## Menjalankan desktop
Setelah Codespace selesai dibuat, jalankan:

```bash
~/start-desktop.sh
```

Buka tab Ports, cari port 6080, lalu buka alamatnya di browser.

## Cek GPU
Jalankan:

```bash
~/check-gpu.sh
```

Catatan: Codespaces tidak otomatis menyediakan RTX 3060 atau GPU khusus. Performa Minecraft bergantung pada resource Codespaces dan dukungan grafis yang tersedia.
